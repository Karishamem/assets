# Свадебные приглашения для гостей

У каждого гостя или пары своя страничка. Сначала гость видит запечатанный конверт с сургучной печатью.
По нажатию конверт открывается, из него выезжает письмо, и появляется приглашение:

1. Кружевная рамка с именами и датой.
2. Личное обращение («Дорогие Иван Петрович и Мария Ивановна») и текст.
3. Календарь недели с сердечком на дате свадьбы.
4. Обратный отсчёт.
5. Программа дня с иконками.
6. Локация, кнопка маршрута и иллюстрация (или ваше фото).
7. Пожелания: подарки и цветы.
8. Дресс-код: карточки «Дамам» и «Джентльменам», палитра цветов.
9. Организатор: телефон, WhatsApp, Telegram.
10. Цитата в сердце.
11. Анкета гостя.

## Где менять данные

Всё редактируется в одном файле `guests.json`. Любой блок можно убрать: удалите его из файла
или оставьте пустым, и он не появится на странице.

| Поле | Что это |
|---|---|
| `couple` | Имена жениха и невесты, инициалы на печати, подпись внизу |
| `event` | Дата (`date` в формате `2026-11-14T15:00:00+03:00`, нужна для отсчёта и календаря), время, место, адрес, ссылка на карту, `photo` (путь к фото площадки, например `venue.jpg`, положите файл в папку `wedding`) |
| `defaultText` | Общий текст приглашения. Каждая новая строка (`\n`) становится абзацем |
| `program` | Пункты программы: `time`, `title`, `note`, `icon`. Иконки: `glasses`, `rings`, `camera`, `dinner`, `dance`, `cake`, `candles`, `fireworks` |
| `wishes` | Пожелания (подарки, цветы). Иконки: `envelope`, `flower` |
| `dressCode` | Общий текст, `ladies`, `gentlemen`, палитра `colors`, ссылка `inspirationUrl` (например, на доску Pinterest) |
| `organizer` | Имя, телефон, `whatsapp` (номер), `telegram` (ник без @) |
| `quote` | Текст в сердце |
| `rsvp` | Настройки анкеты (см. ниже) |
| `guests` | Список гостей |

### Гости

```json
{ "names": "Иван Петрович и Мария Ивановна", "type": "pair" }
```

- `names`: как обращаемся. Например «Елена», «Сергей Николаевич», «Семья Смирновых».
- `type`: `m` даёт «Дорогой», `f` даёт «Дорогая», `pair` даёт «Дорогие». Своё обращение можно указать в поле `greeting`.
- `text` (необязательно): личный текст вместо общего.
- `slug` (необязательно): адрес странички латиницей. Если не указан, он получится из имени.

## Анкета гостей

Анкета спрашивает:
- придёт ли гость и кто именно;
- будут ли дети;
- какое горячее он предпочитает;
- что будет пить;
- есть ли аллергии;
- нужен ли трансфер и ночлег;
- какую песню поставить;
- пожелание молодым.

Варианты ответов настраиваются в `rsvp`: `drinks` и `mains`. Вопросы про детей, трансфер, ночлег и песню
включаются и выключаются полями `askKids`, `askTransfer`, `askStay` и `askSong`.

Чтобы ответы попадали в Google Таблицу:

1. Создайте новую Google Таблицу.
2. Откройте меню «Расширения → Apps Script», удалите код в редакторе и вставьте содержимое файла `rsvp/Code.gs`. Сохраните.
3. Нажмите «Начать развертывание → Новое развертывание», выберите тип «Веб-приложение».
   В пункте «Запуск от имени» выберите себя, в пункте «У кого есть доступ» выберите «Все». Нажмите «Развернуть» и разрешите доступ.
4. Скопируйте ссылку веб-приложения (она заканчивается на `/exec`) и вставьте её в `guests.json` в поле `rsvp.endpoint`.
5. Пересоберите страницы.

Каждый ответ появится в таблице отдельной строкой. В ней будет указано, с чьей странички он пришёл.

## Как собрать страницы

```
node wedding/build.js
```

Появятся папки `wedding/<slug>/index.html` для каждого гостя, общая страница `wedding/index.html`
и файл `wedding/links.md` со списком ссылок для рассылки.

## Как опубликовать

Откройте GitHub → Settings → Pages. В пункте Source выберите «Deploy from a branch», затем ветку с этими файлами и папку `/ (root)`.
Страницы будут открываться по адресу `https://karishamem.github.io/assets/wedding/<slug>/`.
Базовый адрес задаётся в поле `siteUrl` в `guests.json`.

Иконки взяты из набора [Phosphor](https://phosphoricons.com) (лицензия MIT, файл `icons/LICENSE-phosphor`).
