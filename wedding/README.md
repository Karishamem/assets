# Свадебные приглашения для гостей

Для каждого гостя (или пары) — своя страничка с конвертом, который открывается по нажатию,
персональным обращением, датой, местом, обратным отсчётом и падающими лепестками.

## Как поменять данные

Всё редактируется в одном файле — `guests.json`:

- `couple` — имена жениха и невесты, инициалы на печати конверта, подпись;
- `event` — дата (`date` в формате `2026-11-14T15:00:00+03:00` — для обратного отсчёта), текст даты, время, место, адрес, ссылка на карту, дресс-код, контакт. Любое поле можно оставить пустым `""` — блок просто не покажется;
- `defaultText` — общий текст приглашения (на «Вы»);
- `guests` — список гостей:
  - `names` — как обращаемся: «Иван Петрович и Мария Ивановна», «Елена», «Семья Смирновых»;
  - `type` — `m` → «Дорогой», `f` → «Дорогая», `pair` → «Дорогие». Или своё обращение в поле `greeting`;
  - `text` — (необязательно) личный текст вместо общего;
  - `slug` — (необязательно) адрес странички латиницей; если не указан, сделается из имени.

## Как собрать страницы

```
node wedding/build.js
```

Появятся папки `wedding/<slug>/index.html` для каждого гостя, общая страница `wedding/index.html`
и файл `wedding/links.md` со списком ссылок для рассылки.

## Как опубликовать

GitHub → Settings → Pages → Source: «Deploy from a branch», ветка с этими файлами, папка `/ (root)`.
Страницы будут доступны по адресу `https://karishamem.github.io/assets/wedding/<slug>/`
(базовый адрес задаётся в `siteUrl` в `guests.json`).
