# Свадебные приглашения для гостей

У каждого гостя или пары своя страничка. Сначала гость видит запечатанный конверт с бордовой сургучной печатью и бантиком,
на конверте написано его имя. По нажатию конверт открывается, из него выезжает письмо, и появляется приглашение:

1. Имя и отчество гостя крупными буквами.
2. Ваши фото на фоне надписей «I love you».
3. «Мы женимся!» и текст.
4. «Наш день»: числа с сердечком на дате и программа на линии с сердечками.
5. «Ждём вас»: адрес, фото площадки и кнопка карты.
6. Дресс-код с палитрой.
7. «Подарки» и «Чат» с кнопкой «присоединиться».
8. «Увидимся с вами через…»: отсчёт на чёрных плитках.
9. Анкета гостя и контакты организатора.

Фон страницы (`bg.jpg`, чёрно-белый пион с каплями) нарисован генератором, его можно заменить своим фото.

## Где менять данные

Всё редактируется в одном файле `guests.json`. Любой блок можно убрать: удалите его из файла
или оставьте пустым, и он не появится на странице.

| Поле | Что это |
|---|---|
| `couple` | Имена жениха и невесты, инициалы на печати, подпись внизу, `photos`: два ваших фото (например `["photos/1.jpg", "photos/2.jpg"]`, файлы положите в папку `wedding`) |
| `event` | Дата (`date` в формате `2026-11-14T15:00:00+03:00`, нужна для отсчёта и календаря), время, место, адрес, ссылка на карту, `photo` (путь к фото площадки, например `venue.jpg`, положите файл в папку `wedding`) |
| `defaultText` | Общий текст приглашения. Каждая новая строка (`\n`) становится абзацем |
| `program` | Пункты программы: `time` и `title` |
| `wishes` | Блок «Подарки» (`title`, `text`) |
| `chat` | Блок «Чат»: текст и ссылка `url` на чат в Telegram или WhatsApp |
| `dressCode` | Текст и палитра `colors` |
| `organizer` | Имя, телефон, `whatsapp` (номер), `telegram` (ник без @) |
| `rsvp` | Настройки анкеты (см. ниже) |
| `guests` | Список гостей |

### Гости

```json
{ "names": "Иван Петрович и Мария Ивановна", "type": "pair" }
```

- `names`: как обращаемся. Например «Елена», «Сергей Николаевич», «Семья Смирновых».
- `type`: `m` даёт «Дорогой», `f` даёт «Дорогая», `pair` даёт «Дорогие». Своё обращение можно указать в поле `greeting`.
- `text` (необязательно): личный текст вместо общего.
- `slug` (необязательно): адрес странички латиницей. Если не указан, он получится из имени.

## Анкета: ответы в Telegram и таблицу

Каждый ответ гостя приходит вам сообщением в Telegram и одновременно записывается строкой в Google Таблицу.
Посредником служит маленький скрипт Google, поэтому токен бота не попадает на страницу и гости его не видят.

**1. Создайте бота (2 минуты).**
1. В Telegram откройте @BotFather и отправьте `/newbot`.
2. Придумайте имя (например «Анкеты свадьбы») и ник, который заканчивается на `bot`.
3. BotFather пришлёт **токен** вида `123456:ABC...`. Сохраните его и никому не показывайте.
4. Откройте своего нового бота и нажмите «Старт» (или отправьте `/start`).

**2. Создайте таблицу и скрипт (5 минут).**
1. Создайте новую Google Таблицу, например «Свадьба: анкеты».
2. Меню «Расширения → Apps Script». Удалите всё в редакторе и вставьте содержимое файла `rsvp/Code.gs`. Сохраните.
3. Слева «Настройки проекта» (шестерёнка) → «Свойства скрипта» → «Добавить свойство»:
   имя `TELEGRAM_TOKEN`, значение: токен от BotFather. Сохраните.
4. Вернитесь в редактор, выберите вверху функцию `findChatId` и нажмите «Выполнить». Разрешите доступ.
   Скрипт сам найдёт ваш чат с ботом и запомнит его.
5. «Начать развертывание → Новое развертывание» → тип «Веб-приложение».
   «Запуск от имени»: я. «У кого есть доступ»: все. Нажмите «Развернуть».
6. Скопируйте ссылку веб-приложения (заканчивается на `/exec`) и пришлите её мне
   или вставьте в `guests.json` в поле `rsvp.endpoint`, затем пересоберите страницы.

**3. Проверьте.** Откройте любую страничку, заполните анкету: через пару секунд придёт сообщение от бота,
а в таблице появится строка.

Если хотите, чтобы ответы видел и жених, добавьте бота в общий чат с ним, отправьте там `/start`
и снова запустите `findChatId`.

## Как собрать страницы

```
node wedding/build.js
```

Появятся папки `wedding/<slug>/index.html` для каждого гостя, общая страница `wedding/index.html`
и файл `wedding/links.md` со списком ссылок для рассылки.

## Список гостей

Проще всего прислать список в чат одним сообщением, по строке на приглашение:

```
Иван Петрович и Мария Ивановна
Сергей Николаевич
Тётя Света
Семья Смирновых
```

Можно также завести Google Таблицу с колонками «Как обращаемся», «Обращение (Дорогой / Дорогая / Дорогие)»
и «Личный текст» (по желанию) и положить её в папку «свадьба пригласительные».
Для каждой строки получится своя страничка, а в `links.md` будет готовая таблица ссылок для рассылки.

## Где разместить и какой домен

**Рекомендация: Netlify (бесплатно) + свой домен.**
Фото на Netlify не попадают в публичный репозиторий, страницы открываются быстро, HTTPS включается сам.

1. Зарегистрируйтесь на netlify.com (можно через Google).
2. «Add new site → Deploy manually» и перетащите папку `wedding` целиком. Через минуту сайт будет доступен
   по адресу вида `random-name.netlify.app`. В настройках его можно переименовать, например в `vladimir-karina.netlify.app`.
3. Для красивого адреса купите домен у российского регистратора (reg.ru, nic.ru, 2domains.ru), обычно 200-900 ₽ в год.
   Варианты: `vladimir-karina.ru`, `vk-wedding.ru`, `24oktyabrya.ru`, `nasha-svadba24.ru`, `vladimir-i-karina.рф`.
4. В Netlify: «Domain management → Add a domain», введите домен. Netlify покажет, какие DNS-записи прописать у регистратора.
   Через 10-60 минут приглашения будут открываться по ссылкам вида `vladimir-karina.ru/ivanovy/`.

**Другой вариант: GitHub Pages.** Settings → Pages → Deploy from a branch, папка `/ (root)`.
Учтите, что репозиторий публичный: всё, что в нём лежит, включая фото, видно всем.

Рукописный шрифт Allegretto Script One лежит в `fonts/` и встраивается в каждую страницу при сборке.

Иконки взяты из набора [Phosphor](https://phosphoricons.com) (лицензия MIT, файл `icons/LICENSE-phosphor`).
